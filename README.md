# 🎯 JobHunter: автономный ИИ-охотник за работой

Сам ищет вакансии на **24 площадках** (Россия и весь мир), оценивает их ИИ под ваше резюме, пишет живое
сопроводительное письмо на языке вакансии, **сам откликается**, следит за ответами работодателей и присылает в Telegram
готовые результаты: кто ответил, кто зовёт на созвон и что ему ответить.

Работает бесплатно: **Cloudflare Workers + D1 + Workers AI** (сайт, бот, база, ИИ) и **GitHub Actions** (движок сбора).

> Проект собран поверх лучших открытых репозиториев: [JobSpy](https://github.com/speedyapply/JobSpy) (4.7k★, MIT)
> и [dream-job-bot](https://github.com/ev-mironov/dream-job-bot-open-source) (MIT). Их код лежит целиком в `engine/vendor/`,
> а всё, что добавлено сверху, описано ниже. Подробности и лицензии: [NOTICE.md](NOTICE.md).

## Что умеет

| | |
|---|---|
| **24 площадки** | **Россия:** hh.ru, Хабр Карьера, getmatch, «Работа России» (trudvsem), FL.ru, 18 Telegram-каналов, VK-сообщества. **Мир (через JobSpy):** LinkedIn, Indeed, Glassdoor, ZipRecruiter, Google Jobs, Bayt, Naukri, BDJobs, HelloWork. **Удалёнка:** RemoteOK, Remotive, Himalayas, We Work Remotely, Working Nomads, Jobicy, Arbeitnow, Hacker News «Who is hiring» |
| **Склейка дублей** | одна вакансия с hh, Хабра и Telegram превращается в одну карточку, контакты объединяются |
| **Антискам** | `candidate/traps.py` из dream-job-bot (платное обучение, предоплаты, серые схемы) + проверка ИИ |
| **Двойной скоринг** | правила dream-job-bot (зарплата, роль, навыки, формат, гео, риски) + ИИ (соответствие, условия, шанс на оффер). Senior/Lead получают штраф, junior/middle бонус |
| **Человеческие письма** | только факты из резюме; цикл «написал → проверил → исправил» убирает признаки ИИ: длинные тире, «не X, а Y», пересказ вакансии, шаблонные фразы (excited, passionate, «идеально подхожу») |
| **Язык и ссылки** | вакансия на английском → письмо на английском и ссылка **bazadigital.ru/en/**, на русском → по-русски и **bazadigital.ru** |
| **Автоотклики** | hh.ru через официальный API, email через Resend. Telegram-контакты: готовая ссылка, открывающая чат с уже вписанным письмом (одно касание) |
| **Слежение за ответами** | hh.ru: приглашения, отказы, сообщения. Email: входящие через Cloudflare Email Routing. ИИ определяет «хотят созвониться / оффер / вопрос / отказ» и пишет черновик ответа |
| **Telegram-бот** | 🔥 мгновенно о приглашениях, кнопка «Отправить предложенный ответ», утренняя сводка в 9:00 МСК, `/run /status /top /hot /waiting /pause` |
| **Сайт-панель** | кнопка «Запустить», воронка, рейтинг вакансий, история откликов и переписки, все настройки, подключения |

## Что работает полностью само, а что в одно касание

Честно, без преувеличений:

- ✅ **Полностью автоматически:** отклики на **hh.ru** (после входа через hh.ru в панели) и на вакансии с **email** (Хабр, HN, «Работа России», Telegram-посты с почтой), если подключён Resend.
- 👆 **Одно касание:** вакансии из Telegram-каналов с контактом `@username`. Telegram не разрешает ботам писать людям первыми, поэтому бот присылает кнопку, которая открывает чат с HR с уже вписанным письмом: остаётся нажать «Отправить». Писать с вашего личного аккаунта автоматически технически возможно, но аккаунт быстро банят за массовые сообщения, поэтому так не делаю.
- 🌐 **Через сайт работодателя:** LinkedIn, Indeed и другие западные доски ведут на свои формы (ATS). Бот присылает готовое письмо на английском и ссылку.

## Архитектура

```
GitHub Actions (каждые 2 часа и по кнопке)         Cloudflare Worker (бесплатно)
┌──────────────────────────────────────┐   POST    ┌───────────────────────────────────────────┐
│ engine/  Python                      │ ───────▶  │ D1: вакансии, отклики, переписка          │
│  vendor/jobspy_repo  (JobSpy, MIT)   │  ingest   │ Workers AI / Claude: оценка, письма,      │
│  vendor/dreamjob     (dream-job-bot) │           │   разбор ответов                          │
│  jobhunter_engine/   наши улучшения: │ ◀───────  │ Отклики: hh.ru API, Resend, t.me-ссылки   │
│   15 новых источников, дедупликация, │  config   │ Cron каждые 10 мин: оценка → отклик →     │
│   словарь «вайб-кодер», штрафы       │           │   синхронизация ответов                   │
└──────────────────────────────────────┘           │ Telegram-бот (webhook), сайт-панель       │
                                                   │ Email Routing: входящие ответы            │
                                                   └───────────────────────────────────────────┘
```

Почему два места: JobSpy и dream-job-bot написаны на Python и используют библиотеки, которые не запускаются внутри Cloudflare
Workers. GitHub Actions бесплатно выполняет этот Python по расписанию, а Cloudflare держит сайт, бота, базу и ИИ 24/7.

## Установка (≈15 минут)

Нужны Node.js 20+ и аккаунт Cloudflare (бесплатный).

```bash
git clone https://github.com/mm88vin11/JobHunter-.git && cd JobHunter-
bash scripts/setup.sh
```

Скрипт сам создаст базу D1, применит миграции, спросит ключи, задеплоит Worker и покажет адрес панели.
Затем:

1. **GitHub → Settings → Secrets and variables → Actions**: добавьте `WORKER_URL` и `ENGINE_TOKEN` (скрипт их напечатает).
   Движок запускается из ветки по умолчанию, поэтому смёржите код в `main`.
2. Откройте панель → **Подключения** → «Настроить вебхук» → напишите боту `/start <пароль панели>`.
3. **Подключения → Подключить hh.ru** (если задали `HH_CLIENT_ID/SECRET`).
4. Нажмите **🚀 Запустить**.

### Ключи

| Ключ | Обязателен | Где взять | Зачем |
|---|---|---|---|
| `ADMIN_PASSWORD` | да | придумать | вход в панель и привязка бота |
| `TELEGRAM_BOT_TOKEN` | да | [@BotFather](https://t.me/BotFather) → `/newbot` | отчёты и кнопки |
| `ENGINE_TOKEN` | да | создаёт `setup.sh` | связь движка и Worker |
| `HH_CLIENT_ID`, `HH_CLIENT_SECRET` | для автооткликов на hh.ru | [dev.hh.ru](https://dev.hh.ru) → «Зарегистрировать приложение», Redirect URI: `https://<ваш-worker>/auth/hh/callback` | поиск и отклики на hh.ru |
| `ANTHROPIC_API_KEY` | нет | [console.anthropic.com](https://console.anthropic.com) | письма заметно лучше, чем у бесплатной Llama |
| `RESEND_API_KEY` + «Email отправителя» в настройках | нет | [resend.com](https://resend.com), подтвердить домен bazadigital.ru | автоотклики письмом |
| `VK_SERVICE_TOKEN` | нет | vk.com/apps?act=manage → приложение → сервисный ключ | VK-сообщества |
| `GITHUB_TOKEN` | нет | GitHub → fine-grained token, Actions: Read and write на этот репозиторий | мгновенный запуск сбора по кнопке |

Входящие ответы на email-отклики: Cloudflare → Email Routing для домена → правило `jobs@ваш-домен` → «Send to Worker: jobhunter»,
и укажите этот адрес в поле Reply-To в настройках.

## Настройка под себя

Всё меняется в панели (вкладка **Настройки**): резюме RU/EN (ИИ берёт факты только оттуда), запросы, Telegram-каналы,
стоп-слова, пороги автоотклика, лимит откликов в сутки (по умолчанию 40, чтобы не выглядеть как спам), «только удалёнка»,
минимальная зарплата, включение и выключение площадок.

## Разработка

```bash
npm install && npm test && npm run typecheck       # Worker
pip install -r engine/requirements.txt pytest && pytest engine/tests
cd engine && python -m jobhunter_engine.run --dry-run --only habr,telegram,remoteok   # сбор без Worker → results.json
npx wrangler dev                                    # Worker локально (Workers AI требует входа в Cloudflare)
```

## Лимиты бесплатных тарифов

- Workers AI: 10 000 «нейронов» в день, это примерно 150–300 оценок и писем. Хватает при 40 откликах в сутки; с `ANTHROPIC_API_KEY` ограничения нет.
- GitHub Actions: 2 000 минут в месяц для приватного репозитория, поэтому сбор идёт раз в 2 часа (~4 минуты за запуск). В публичном репозитории можно ставить каждые 30 минут.
- hh.ru: до 200 откликов в сутки на резюме; вакансии с обязательным тестом бот не отправляет сам, а присылает вам.
